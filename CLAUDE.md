# downmark

Lightweight Markdown editor/renderer for Linux. Rust, GTK4, libadwaita, GtkSourceView 5, WebKitGTK 6.0, pulldown-cmark. Plan and tasks: `tasks/plan.md`, `tasks/todo.md`.

## Commands
- Run: `cargo run`
- Test: `cargo test`
- Lint: `cargo clippy --all-targets -- -D warnings`

## Code
- `src/render.rs` is pure (Markdown → HTML, page shell, preview update script) and unit-tested. Keep GTK out of it.
- `src/main.rs` holds the app and window.
- New logic in `render.rs` gets a test first.

## Commits
- No `Co-Authored-By: Claude` trailer.
- No "Generated with Claude Code" / "coded with Claude" lines or tags in commits, PRs or releases.
- Short imperative subject, concise body only when needed.

## Releases
GitHub Actions (`.github/workflows/release.yml`) builds and publishes on a `v*` tag push.
1. Bump `version` in `Cargo.toml`, run `cargo build` to update `Cargo.lock`, commit.
2. `git tag -a vX.Y.Z -m "<brief summary of what changed since the last release>"`
3. `git push origin main vX.Y.Z`

Release notes = tag message + commit list since the previous tag (generated by git) + compare link.
