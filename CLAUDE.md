# downmark

Lightweight Markdown editor/renderer for Linux. Rust, GTK4, libadwaita, GtkSourceView 5, WebKitGTK 6.0, pulldown-cmark. Plan and tasks: `tasks/plan.md`, `tasks/todo.md`.

## Commands
- Run: `cargo run`
- Test: `cargo test`
- Lint: `cargo clippy --all-targets -- -D warnings`

## Code
- `src/render.rs`: Markdown → HTML, page shell, preview update script. Pure, unit-tested, no GTK.
- `src/settings.rs`: theme + shortcut table, KeyFile load/save, conflict detection. Pure, unit-tested.
- `src/window.rs`: one document window (editor, preview, files, export) plus pure helpers with tests.
- `src/prefs.rs`: settings dialog (theme, export buttons, shortcut rebinding).
- `src/main.rs`: app setup, applies accels and theme.
- New logic gets a test first. GUI is checked manually.
- `data/`: desktop file, icon, metainfo, screenshot. `make install PREFIX=… DESTDIR=…` installs everything.
- `packaging/PKGBUILD`: AUR package, updated after each release (pkgver + sha256sums, regenerate `.SRCINFO`).

## Releases
Full guide incl. AUR and key setup: `PUBLISHING.md`.

GitHub Actions (`.github/workflows/release.yml`) builds and publishes on a `v*` tag push.
1. Bump `version` in `Cargo.toml`, run `cargo build` to update `Cargo.lock`, add a `<release>` to the metainfo, commit.
2. `git tag -a vX.Y.Z -m "<brief summary of what changed since the last release>"`
3. `git push origin main vX.Y.Z`

4. Update `packaging/PKGBUILD` (pkgver, sha256sums), `makepkg --printsrcinfo > .SRCINFO`, commit, push to AUR.

Release notes = tag message + commit list since the previous tag (generated by git) + compare link.
